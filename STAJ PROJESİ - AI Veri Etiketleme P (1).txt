STAJ PROJESİ - AI Veri Etiketleme Platformu (Label Studio Benzeri)

============================================================

1. PROJENİN AMACI
   ============================================================

Makine öğrenmesi ve yapay zekâ projelerinde modellerin eğitilebilmesi için etiketlenmiş verilere ihtiyaç vardır.

Bu projede amaç, kullanıcıların veri yükleyip etiketleme yapabileceği web tabanlı bir sistem geliştirmektir.

Geliştirilecek sistem temel olarak aşağıdaki görevleri destekleyecektir:

* Metin Sınıflandırma (Text Classification)
* Varlık Tanıma (NER - Named Entity Recognition)
* Resim Sınıflandırma (Image Classification)

Bu proje, açık kaynaklı Label Studio ürününün temel mantığını anlamak ve daha sade bir versiyonunu geliştirmek amacıyla yapılacaktır.

3. DESTEKLENECEK ANNOTATION TİPLERİ
===================================

Bu projede 3 farklı annotation tipi geliştirilecektir.

---

## A. TEXT CLASSIFICATION

Örnek Metin:

"Bu telefonun kamerası çok başarılı."

Etiketler:

* Pozitif
* Negatif
* Nötr

Amaç:

Bir metnin hangi kategoriye ait olduğunu belirlemek.

Kullanım Alanları:

* Sentiment Analysis
* Spam Tespiti
* Haber Kategorilendirme
* Müşteri Geri Bildirimi Analizi

---

## B. NAMED ENTITY RECOGNITION (NER)

Örnek:

"Ahmet bugün İstanbul'da Microsoft ofisini ziyaret etti."

Etiketler:

* Ahmet → PERSON
* İstanbul → LOCATION
* Microsoft → ORGANIZATION

Amaç:

Metin içerisindeki önemli varlıkları işaretlemek.

Kullanım Alanları:

* Doküman Analizi
* Hukuk Sistemleri
* Sağlık Sistemleri
* Chatbotlar

---

## C. IMAGE CLASSIFICATION

Örnek:

* Resim → Kedi
* Resim → Köpek
* Resim → Araba

Amaç:

Bir görüntünün hangi sınıfa ait olduğunu belirlemek.

Kullanım Alanları:

* Ürün Kategorilendirme
* Kalite Kontrol
* Görsel Arama

6. ANNOTATION EKRANLARI
=======================

---

## 6.1 Text Classification Ekranı

Sol tarafta:

* Metin

Sağ tarafta:

* Etiketler

Örnek:

( ) Pozitif
( ) Negatif
( ) Nötr

Butonlar:

* Kaydet
* Sonraki

---

## 6.2 NER Ekranı

Metin gösterilir.

Kullanıcı fare ile kelime veya kelime grubu seçer.

Açılan menü:

* PERSON
* LOCATION
* ORGANIZATION

Seçilen alan renklendirilir.

Butonlar:

* Kaydet
* Geri Al
* Sonraki

---

## 6.3 Image Classification Ekranı

Resim gösterilir.

Altında etiketler bulunur.

Örnek:

( ) Kedi
( ) Köpek
( ) Araba

Butonlar:

* Kaydet
* Sonraki

---

## 6.4 Object Detection Ekranı

Resim gösterilir.

Kullanıcı mouse ile kutu çizer.

Kutuyu seçince etiket atanır.

Örnek etiketler:

* Person
* Car
* Bicycle

Sistem aşağıdaki bilgileri saklar:

* x
* y
* width
* height
* label
